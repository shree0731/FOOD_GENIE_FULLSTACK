# Food Genie - Fullstack AI Recipe Generator

An intelligent culinary web application that takes whatever ingredients you have in your pantry and turns them into delicious, structured, cookable recipes using Groq AI.

## Project Structure
- `backend/`: Node.js Express API powered by Groq SDK (LLaMA 3.1 8B Instant).
- `frontend/`: React + Vite single page application with modern UI components.
